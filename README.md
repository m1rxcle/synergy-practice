# Synergy Practice

Это проект, в котором собрана практика от **Synergy**.  
Каждое задание вынесено в отдельную **ветку** с соответствующей структурой файлов.  
Ниже приведена структура проекта по веткам:

```text
synergy-practice/
├── (Branch №1) first-test-case/      # Простое тестовое задание на Go
│   ├── .gitignore                     # Игнорируемые файлы
│   ├── first-test-case.go             # Основной код теста
│   ├── go.mod                         # Модуль Go
│   └── README.md                       # Описание задания
├── (Branch №2) second-test-case/     # Тестовое задание на JS/HTML/CSS
│   ├── app.js                         # Логика приложения
│   ├── index.html                     # Главная страница
│   ├── style.css                      # Стили
│   └── README.md                       # Описание задания
├── (Branch №3) third-test-case/      # Ещё одно задание на JS/HTML/CSS
│   ├── app.js
│   ├── index.html
│   ├── style.css
│   └── README.md
└── (Branch №4) fourth-test-case/     # Ещё одно задание на JS/HTML/CSS
    ├── app.js
    ├── index.html
    ├── style.css
    └── README.md
```
